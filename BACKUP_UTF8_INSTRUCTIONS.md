# Бэкап и восстановление базы данных с поддержкой русского языка

## Описание

Эти скрипты обеспечивают корректное создание и восстановление бэкапов базы данных с правильной кодировкой UTF-8, что позволяет избежать проблем с отображением русского текста (Mojibake).

## Скрипты

1. `backup-database-utf8.sh` - для Linux/Mac (или WSL)
2. `backup-database-utf8.ps1` - для Windows PowerShell
3. `restore-database-utf8.sh` - для Linux/Mac (или WSL)
4. `restore-database-utf8.ps1` - для Windows PowerShell

## Использование

### На Linux/Mac:

#### Создание бэкапа:
```bash
chmod +x scripts/backup-database-utf8.sh
./scripts/backup-database-utf8.sh
```

#### Восстановление из бэкапа:
```bash
chmod +x scripts/restore-database-utf8.sh
./scripts/restore-database-utf8.sh
```

### На Windows:

#### Создание бэкапа:
```powershell
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
.\scripts\backup-database-utf8.ps1
```

#### Восстановление из бэкапа:
```powershell
.\scripts\restore-database-utf8.ps1
```

## Особенности

- Все скрипты используют явное указание кодировки UTF-8 при создании и восстановлении бэкапов
- Скрипты автоматически считывают параметры подключения из файла `.env`
- Реализованы меры безопасности при восстановлении данных
- Автоматическое логирование операций бэкапа и восстановления

## Важные замечания

1. Для корректной работы необходимо, чтобы PostgreSQL контейнер был запущен с поддержкой русской локали (как это было настроено ранее)
2. При создании бэкапа убедитесь, что база данных находится в согласованном состоянии
3. При восстановлении все текущие данные будут перезаписаны
4. Рекомендуется протестировать восстановление на тестовой среде перед выполнением на проде

## Решение проблемы с кодировкой

Для предотвращения проблемы с кодировкой текста в будущем:

1. Убедитесь, что все данные вводятся в систему с правильной кодировкой
2. Используйте только обновленные скрипты для создания и восстановления бэкапов
3. При переносе данных из старых бэкапов используйте конвертацию кодировки (как это было сделано в процессе решения проблемы)
