# Кликабельные метки в Log Analytics

## Новая функциональность

Добавлена возможность фильтрации логов через кликабельные метки в интерфейсе админки Log Analytics.

## Что реализовано

### 1. Кликабельные метки в результатах поиска логов

В каждой записи лога теперь доступны следующие кликабельные метки:

- **User ID** - фильтрация по конкретному пользователю
- **Session ID** - фильтрация по конкретной сессии  
- **Correlation ID** - переход к анализу цепочки вызовов
- **Module** - фильтрация по модулю приложения

### 2. Кликабельные метки в цепочке вызовов (Call Chain)

В результатах анализа цепочек вызовов также добавлены:

- **Correlation ID** - повторный поиск по тому же correlation ID
- **User ID** - фильтрация всех логов по пользователю
- **Session ID** - фильтрация всех логов по сессии

## Как использовать

1. Перейдите в админку → Log Analytics
2. В результатах поиска найдите интересующую запись лога
3. Кликните по любой из меток:
   - **User: xxxxxxxx** - автоматически отфильтрует все логи для этого пользователя
   - **Session: xxxxxxxx** - покажет все действия в рамках этой сессии
   - **Correlation: xxxxxxxx** - откроет анализ цепочки вызовов
   - **ModuleName** - отфильтрует логи по этому модулю

## Визуальные улучшения

- Метки имеют курсор указателя при наведении
- При наведении цвет фона слегка изменяется для лучшей обратной связи
- Плавные переходы для улучшения UX
- Адаптивная верстка с `flex-wrap` для корректного отображения на мобильных устройствах

## Технические детали

Файл изменений: `client/src/components/LogAnalytics.tsx`

Основные изменения:
- Добавлены обработчики `onClick` для меток
- Использованы существующие функции `setFilters()` и `searchLogs()`
- Для цепочек вызовов добавлен переход между табами
- Все метки теперь имеют класс `cursor-pointer` и эффекты hover

## Пример использования

```
// При клике на User ID метка:
<User className="w-3 h-3 mr-1" />
User: abc12345...

// Автоматически применяет фильтр:
setFilters({...filters, userId: 'abc12345-xxxx-xxxx-xxxx-xxxxxxxxxxxx'});
searchLogs({...filters, userId: 'abc12345-xxxx-xxxx-xxxx-xxxxxxxxxxxx'}, 0);
```

Эта функциональность значительно ускоряет анализ логов и поиск связанных событий в системе.
