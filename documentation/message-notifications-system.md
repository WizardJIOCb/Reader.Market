# Message Notifications System

## Overview

Реализована система всплывающих уведомлений о новых сообщениях в правом нижнем углу экрана с возможностью перехода в чат.

## Что реализовано

### 1. MessageNotificationProvider

**Файл:** `client/src/components/MessageNotificationProvider.tsx`

Глобальный провайдер, который:
- Слушает WebSocket события `message:new` (приватные сообщения)
- Слушает WebSocket события `channel:message:new` (групповые сообщения)
- Показывает всплывающие уведомления через `useToast`
- Предоставляет кнопки для перехода в соответствующие чаты

### 2. Интеграция в App

**Файл:** `client/src/App.tsx`

Провайдер интегрирован в дерево компонентов:
```tsx
<StreamNotificationsProvider currentUserId={user?.id}>
  <MessageNotificationProvider currentUserId={user?.id}>
    {/* Приложение */}
  </MessageNotificationProvider>
</StreamNotificationsProvider>
```

### 3. Обработка фокусировки в Messages

**Файл:** `client/src/pages/Messages.tsx`

Добавлены обработчики событий:
- `focus-conversation` - для открытия приватного чата
- `focus-group` - для открытия группового чата

## Функциональность

### Уведомления о приватных сообщениях:
- Показывают имя отправителя
- Показывают превью сообщения (первые 50 символов)
- Кнопка "Open chat" для перехода в диалог
- Не показываются для сообщений от самого пользователя

### Уведомления о групповых сообщениях:
- Показывают название группы
- Показывают имя отправителя и превью сообщения
- Кнопка "Open group chat" для перехода в группу
- Не показываются для сообщений от самого пользователя

## Технические детали

### События WebSocket:
- `message:new` - новые приватные сообщения
- `channel:message:new` - новые групповые сообщения

### События фокусировки:
- `focus-conversation` - событие для открытия приватного чата
- `focus-group` - событие для открытия группового чата

### Навигация:
- Используется Wouter router (`useLocation`)
- Переход осуществляется через `setLocation('/messages')`
- Дополнительная фокусировка через Custom Events

## Пример использования

```tsx
// В уведомлении о новом приватном сообщении:
title: "New message from John Doe"
description: "Hello! How are you? [Open chat button]"

// В уведомлении о новом групповом сообщении:
title: "New message in Book Club"
description: "Jane Smith: Let's discuss the next book [Open group chat button]"
```

## Особенности реализации

1. **Условия показа уведомлений:**
   - Только для сообщений от других пользователей
   - Не показываются, если пользователь сам отправил сообщение

2. **Длительность показа:**
   - 8 секунд (дольше стандартных уведомлений)

3. **Переход в чат:**
   - Переход на страницу `/messages`
   - Автоматическая фокусировка на нужном диалоге/группе
   - Работает как на десктопе, так и на мобильных устройствах

4. **Интеграция с существующими системами:**
   - Совместим с StreamNotificationsProvider
   - Использует тот же механизм toast уведомлений
   - Не конфликтует с другими уведомлениями

## Тестирование

Для проверки работы системы:

1. Откройте два браузера с разными аккаунтами
2. Отправьте сообщение от одного пользователя другому
3. Убедитесь, что появляется всплывающее уведомление в правом нижнем углу
4. Нажмите кнопку "Open chat" - должно произойти перенаправление в чат
5. Проверьте, что нужный диалог/группа автоматически выбраны

## Расширяемость

Систему можно легко расширить:
- Добавить звуковые уведомления
- Настроить различные типы уведомлений для разных действий
- Добавить настройки отключения уведомлений
- Реализовать группировку уведомлений
